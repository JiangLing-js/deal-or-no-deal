# 成交还是不成交

![成交还是不成交游戏预览](./public/og.png)

一个使用 React 和 TypeScript 制作的单人网页开箱游戏。玩家从 20 个箱子中保留一个属于自己的箱子，在逐轮开箱的过程中衡量风险，并在银行家的报价面前选择“成交”或“不成交”。

> 本项目是独立制作的玩法演示，与任何电视节目、制作公司或商标持有人均无隶属、授权或合作关系。游戏不涉及真实货币或真实奖金。

## 游戏玩法

1. 从 20 个箱子中选择一个作为自己的箱子。
2. 按照 `6 → 5 → 4 → 3` 的顺序逐轮打开其他箱子。
3. 每轮结束后，银行家会根据所有剩余金额的期望值给出动态报价。
4. 选择“成交”即可锁定报价；选择“不成交”则继续开箱。
5. 只剩两个箱子时，可以保留原箱或与最后一个箱子交换，然后揭晓最终奖金。

20 箱模式在打开 `6 + 5 + 4 + 3 = 18` 个箱子后正好剩下两个箱子，因此会直接进入最终换箱阶段。

## 特性

- 20 个随机箱子，奖金范围从 `$0.01` 到 `$1,000,000`
- 基于剩余金额、游戏轮次与高额奖金数量计算银行家报价
- 完整的成交、不成交、换箱和结算流程
- 自适应桌面端与移动端布局
- 支持键盘焦点、语义标签和减少动态效果偏好
- 纯前端运行，不需要账号、数据库或后端服务
- 不使用分析服务，不收集、上传或持久化玩家数据

## 本地运行

需要 Node.js `22.13.0` 或更高版本。

```bash
npm install
npm run dev
```

打开终端中显示的本地地址即可开始游戏。

正式构建与本地预览：

```bash
npm run build
npm run start
```

## 技术栈

- TypeScript
- Vinext / Vite
- Tailwind CSS
- Base UI
- Lucide Icons

## 项目结构

```text

├─ layout.tsx         # 页面元数据和根布局
└─ page.tsx           # 主要状态与游戏流程
components/ui/        # 实际使用的基础按钮和弹窗组件
lib/                  # 样式工具
public/               # 图标和项目预览图
```
